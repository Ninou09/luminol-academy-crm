Ты работаешь над репозиторием `Ninou09/luminol-academy-crm`. Это CRM академии в Алжире: консультации психолога, языковые курсы, тренинги.
- **Стек:** React + Vite (`src/`), Express + SQLite (`server/`), деплой на Vercel, миграции в `server/migrations/` (последняя — `015_platform.sql`).
- **Языки:** FR по умолчанию, AR справа налево, EN. Словари в `src/french.ts` и `src/i18n.ts`.
- **Роли:** Directeur (`admin`), Administrateur (`manager`), Secrétaire (`admissions`), Enseignant (`instructor`). Права проверяются на сервере.
- **Уже есть:** `server/ai.mjs` (резюме клиента, черновик сообщения, «что делать», вопросы к цифрам), входящие `messages`, сценарии `flows`, сегменты, формы, API v1, webhooks.

## Правила работы
- Перед кодом с Claude API прочитай skill `claude-api`. Используй официальный SDK `@anthropic-ai/sdk` и модель `claude-opus-5-5`. Для простой сортировки и классификации — `claude-haiku-5-5`. Включи `fallbacks: "default"` с beta `server-side-fallback-2026-07-01`, обрабатывай `stop_reason: "refusal"`. Длинные ответы — потоком (streaming). Для постоянного системного текста и справки используй кэширование промптов.
- **Приватность (закон 18-07):** заметки психолога (`session_notes`), анкеты (`intake_forms`), медицинские данные и документы никогда не уходят в ИИ. Это проверяет тест.
- **Без ключа `ANTHROPIC_API_KEY`** всё ИИ скрыто, CRM работает как раньше. Директор может выключить ИИ одной галочкой.
- **Лимит расходов в месяц** задаётся в настройках. Каждый вызов записывается: кто, что, сколько токенов. Директору виден счётчик.
- Каждое изменение базы — новой миграцией, ничего не теряй. Тесты в `tests/`, без настоящих вызовов API: подменяй клиента.
- Переводи все новые тексты на FR и AR. Проверяй экраны на 1440 и 390 px, в тёмной теме и на арабском.
- Пользователи не технические: всё крупно и понятно, на телефоне тоже.
- **Не коммить и не отправлять в GitHub или Vercel без слова «отправляй».** Присылай превью: скриншоты в артефакте.

Делай по порядку, самое полезное сначала.

## 1. Чат-помощник для сотрудников «Demander à Luminol»
- Кнопка-пузырь в углу на каждой странице. Окно чата, на телефоне — во весь экран.
- **Знает систему:** собери справку `docs/help/*.md` (FR, по одной странице на раздел CRM: как записать клиента, принять оплату, создать сценарий…). Помощник отвечает по ней и даёт кнопку «Открыть эту страницу».
- **Знает данные через инструменты (только чтение)**, с правами текущего пользователя: `search_clients`, `client_overview` (без психологических заметок), `agenda(day, staff)`, `unpaid`, `stats(metric, group_by, period)`, `open_requests`, `free_slots(service, date)`. Например: «Кто не оплатил в ноябре?», «Есть ли свободное время у Dr Amrani в четверг?»
- **Действия только после подтверждения:** «Создать задачу», «Подготовить WhatsApp», «Записать на приём». Помощник показывает карточку с кнопками «Confirmer / Annuler» и сам ничего не меняет.
- Отвечает на языке вопроса (FR / AR / дарджа). Если не знает, так и говорит.
- История чата у каждого своя, хранится 30 дней. Новые таблицы: `ai_chats`, `ai_messages`, `ai_usage`.

## 2. Чат-бот для клиентов в WhatsApp и на сайте (24/7)
- Отвечает на частые вопросы по базе знаний, которую ведёт директор («Paramètres → Base de connaissances»): цены, адрес, часы, программы, оплата.
- **Сам записывает** на свободное время через существующую онлайн-запись. Подтверждение «1 / 2» уже есть.
- Понимает намерение входящего сообщения (`claude-haiku-5-5`): запись, перенос, цена, жалоба, срочно. Ставит метку в «Messages» и сразу передаёт человеку, если это жалоба, срочный случай или он не уверен.
- **Психологическая безопасность:** если в сообщении есть признаки кризиса (суицидальные мысли, насилие), бот не консультирует. Он сразу передаёт сообщение дежурному специалисту с уведомлением «срочно» и даёт номера экстренной помощи Алжира. Тексты для этого случая утверждает директор.
- Виджет чата для сайта: код `<script>` в «Paramètres → Site web», FR/AR.
- Режим «только черновики»: бот готовит ответ, секретарь нажимает «Envoyer». По умолчанию включён на первые 2 недели.

## 3. Прогнозы (машинное обучение на своих данных, без внешних сервисов)
Считай на сервере простыми моделями: логистическая регрессия или градиентный бустинг на JS. Переобучай раз в неделю по cron. Показывай понятные причины, а не только цифру.
- **Риск неявки** для каждой записи (история клиента, время, день, давность записи, подтвердил ли). Высокий риск → лишнее напоминание и пометка в календаре.
- **Риск ухода клиента** (давно не был, пропуски, долги, оценки). Список «à rappeler cette semaine».
- **Скоринг заявок:** вероятность, что заявка станет клиентом (источник, услуга, скорость первого ответа). Заменяет текущую «горячесть».
- **Лучшее время для записи и для рассылки** по каждой услуге.
- **Прогноз загрузки залов и специалистов** на 4 недели: где открыть ещё группу.
- Пока данных мало (меньше ~200 записей), показывай правила-эвристики с подписью «оценка».
- Таблицы: `ml_models` (версия, метрики, дата), `ml_scores` (запись → оценка + причины). Страница «Prévisions» для директора: точность модели на прошлых данных.

## 4. ИИ в повседневной работе
- **Фото чека или квитанции CCP/BaridiMob** → Claude (зрение) читает сумму, дату и номер → готовый черновик оплаты, сотрудник проверяет.
- **Фото документа или анкеты на бумаге** → поля клиента заполняются (кроме медицинских).
- **Анализ отзывов:** настроение и темы («ожидание», «цена», «специалист») в отчётах.
- **Умный поиск:** «клиентка из Блиды, которая хотела английский B1» находит нужную карточку.
- **Резюме недели для директора:** 5 пунктов, что изменилось и что сделать. Приходит по почте и в уведомления.
- **Проверка текста рассылки** перед отправкой: тон, ошибки, перевод FR ↔ AR.

## 5. Другое полезное
- **Интерактивное обучение:** при первом входе — тур по своей роли (5–7 шагов) и чек-лист «Premiers pas».
- **Личный кабинет клиента как приложение (PWA):** записи, оплата, материалы, сообщения, push.
- **Голосовые сообщения WhatsApp:** сохранять как вложение в «Messages» с кнопкой «écouter». Расшифровка потребует отдельного сервиса распознавания речи — только предложи.
- **Резервная копия в один клик** и проверка, что копия открывается.
